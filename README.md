# laco-repeticao-while

# Exercícios de Lógica de Programação com JavaScript 🚀

Este repositório contém uma série de exercícios práticos desenvolvidos para exercitar o uso de estruturas de repetição (`while` e `do...while`) em JavaScript.

## 📋 Desafios Desenvolvidos

### 1. Validação de Número Positivo
O programa solicita um número ao usuário e só interrompe a execução quando um valor positivo é inserido.
* **Conceito:** Validação de entrada e controle de fluxo.

### 2. Cálculo de Média de Notas
Permite a inserção indefinida de notas (0 a 10). O laço é encerrado ao digitar um número negativo, exibindo em seguida a média aritmética das notas válidas.
* **Conceito:** Acumuladores, contadores e sentinelas de parada.

### 3. Totalizador de Compras (Ponto de Venda)
Simula um caixa onde o usuário insere os valores dos produtos. Ao digitar `0`, o sistema exibe o valor total acumulado da compra.
* **Conceito:** Soma acumulada (Operador `+=`).

### 4. Validação de Nome Completo
O programa solicita primeiro nome e sobrenome separadamente. Caso o usuário deixe algum campo vazio ou insira apenas espaços, o sistema repete a pergunta até obter uma resposta válida.
* **Conceito:** Manipulação de Strings e operadores lógicos (`||`).

### 5. Simulação de Saque Bancário
Com um saldo inicial pré-definido, o usuário realiza saques. O programa valida se há saldo suficiente antes de processar a operação e encerra automaticamente quando o saldo chega a zero ou se torna insuficiente.
* **Conceito:** Decréscimo de valores e condicionais aninhadas dentro de loops.
